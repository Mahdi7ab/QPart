# طراحی سایت

این فولدر محل نگهداری خروجی‌ها، تصمیم‌ها و تسک‌های طراحی سایت است.

نمونه اولیه قابل مشاهده صفحه اصلی در `prototype/index.html` قرار دارد. تصاویر نمونه در `prototype/assets/` قرار گرفته‌اند.

## وضعیت فعلی

نمونه UI استاتیک صفحه اصلی آماده است و باید پس از نهایی‌شدن نیازمندی‌ها به پیاده‌سازی محصول تبدیل شود.

## فایل‌های این فولدر

- `01-discovery-and-requirements.md` — نیازمندی‌های استخراج‌شده و پرسش‌های باز
- `02-information-architecture.md` — معماری اطلاعات و نقشه سایت
- `03-product-model-and-categories.md` — مدل داده محصول و دسته‌بندی‌ها
- `04-order-and-supply-flow.md` — مسیر سفارش، تأمین و پیگیری
- `05-wireframes.md` — وایرفریم صفحات اصلی
- `06-visual-design-system.md` — سیستم بصری و اجزای UI
- `07-responsive-and-accessibility.md` — ریسپانسیو، RTL و دسترس‌پذیری
- `08-content-and-assets.md` — محتوای محصولات و دارایی‌های بصری
- `09-prototype-and-review.md` — نمونه اولیه و بازبینی
- `10-handoff-and-qa.md` — تحویل برای پیاده‌سازی و کنترل کیفیت
- `11-reference-site-audit.md` — تحلیل سایت‌های مرجع
- `12-refactoring-ui-design-system.md` — سیستم بصری و توکن‌های طراحی
- `13-homepage-and-flow-spec.md` — مشخصات صفحه اصلی و مسیرهای کلیدی
- `14-routes-and-component-inventory.md` — قرارداد مسیرها و فهرست کامپوننت‌ها

هر تسک باید پس از تکمیل، خروجی مشخص و وضعیت آن در فایل ریشه `Website Design Tasks.md` به‌روزرسانی شود.
